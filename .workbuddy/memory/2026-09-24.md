## WebTerm —— Node.js SSH 客户端（对标 SecureCRT）

**任务**：为用户设计一款基于 Node.js 的 SSH 客户端，整理功能框架说明文件与需求，给出实现计划（本轮只出文档，未写代码）。

**已确认的决策（用户选择）**
- 应用形态：**本地 Node.js 服务 + 浏览器访问**（B/S，非 Electron）
- 首版范围：**完整功能版**（非 MVP）
- 前端栈：**React + TypeScript + Tailwind**

**产出文件**
- `docs/01-功能框架与需求说明书.md` —— 产品定位、架构、技术选型、F1~F10 功能清单（MoSCoW 分级）、非功能需求、5 项关键设计决策、SQLite 数据模型、REST + WS 接口协议、风险对策、验收标准
- `docs/02-实现计划.md` —— 9 个阶段（阶段0 骨架 → 阶段8 插件打包）、每阶段任务/验收清单、工作量汇总（约 14 人日）、测试策略、环境与运行方式、5 个待确认决策点

**关键技术决策（后续写代码须遵守）**
1. 终端 I/O 走 WebSocket **binary frame**，控制消息走 text JSON —— 避免 base64 的 33% 膨胀
2. 编码转换放在**服务端**（iconv-lite + StringDecoder 累积不完整多字节），前端始终按 UTF-8 处理
3. `Session`（持久化配置）与 `TerminalSession`（运行时标签）解耦；会话表只存 `credential_id`，凭据独立加密表
4. 背压：服务端累积 ≥64KB 时 `channel.pause()`，前端 ACK 后 `resume()`
5. 脚本沙箱用 `node:vm` + 白名单 API（**不用 vm2**，已停止维护且有逃逸漏洞）
6. 凭据加密：scrypt 派生主密钥（仅内存）+ AES-256-GCM；服务默认只绑 `127.0.0.1`

**锁定版本**：ssh2 1.17 / fastify 5.12 / better-sqlite3 13（要求 node ≥22）/ @xterm/xterm 6.0 / iconv-lite / zod / Vite 7 / Tailwind 4
