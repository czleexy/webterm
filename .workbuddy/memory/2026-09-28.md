**关键设计决策**
1. 凭据加密存 DB，**不落 `data/keys` 明文文件** —— 文件被误拷走的风险大于库文件
2. `vault.verifier` 用「已知明文的 AES-GCM 密文」代替独立哈希：解锁成功即证明主密码正确，无额外比较逻辑
3. 未解锁时 `/api/terminals`、`/api/sessions/probe` 返回 **423 Locked**（而非 401），与「认证失败」区分
4. 凭据删除做引用检查（含跳板链），返回 409 + 引用计数，避免删掉后被会话静默引用
5. 跳板链每跳独立走算法降级与 TOFU 校验；链条任何一环失败即回收已建立的中间连接
6. 解锁不落浏览器存储：主密码只保护磁盘密文，存 localStorage 等于钥匙挂锁上
